# Release Notes - Firefly v1.0.10

## New Feature: Accessibility Converter

A new **Accessibility Converter** tool has been added to the sidebar under the Tools section. This feature simulates Android accessibility visual effects on images, useful for testing and QA.

### Conversion Modes
- **Colour Inversion** — Inverts lightness in HSL space while preserving hue and saturation
- **Colour Correction** — Applies Android's Protanomaly matrix simulation (red-green colour blindness)

### Highlights
- Batch convert multiple images at once (PNG, JPG, BMP, GIF, WebP)
- Choose output folder via save dialog
- Thumbnail previews for all added images with converted result previews
- Animated success dialog with "Show in Folder" quick action
- Layout matches the existing Configuration view for a consistent look and feel
